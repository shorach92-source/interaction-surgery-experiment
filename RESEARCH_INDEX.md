# Research Index — Canonical

This file is the numbering and decision source of truth for the falsification-first research program.

## Governance

1. Search competition / prior art before creating a candidate.
2. A candidate number is reserved by adding it here **before** adding experiment files or workflows.
3. Freeze hypothesis, strong baseline(s), metrics and kill criteria before the first live result.
4. A failed kill criterion closes the candidate. Do not tune observed cases to rescue it; a materially different hypothesis receives a new number and a fresh prior-art search.
5. Constructed fixtures validate plumbing only. A novelty claim requires real evidence, replication, renewed prior-art search and independent scrutiny.
6. Existing classical methods that solve the core problem count as a kill even if the exact LLM/restaurant application has not been published.
